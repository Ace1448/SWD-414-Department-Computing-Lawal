# Department of Computing Website — SWD 414

A responsive, static demonstration website created for the assignment on Version Control, Git and GitHub.

## Pages
- `index.html` — Home page
- `about.html` — About Us page
- `programmes.html` — Sample programme list
- `contact.html` — Contact page with a front-end demonstration form
- `style.css` — Shared styling
- `script.js` — Contact form demo interaction

## Run the website
Open `index.html` in a web browser. No build tools are required.

## Important
The programme names and contact details are examples. Replace them with approved institutional information before submission. The contact form does not send messages to a server.

## Suggested Git practical
Follow `GIT_GITHUB_GUIDE.md` to demonstrate commits, a feature branch, a merge, and pushing to GitHub.

## Assignment update
The project includes a contact page feature branch merged into `main` in the local demonstration repository.
